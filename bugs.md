# Known Bugs & Issues — OneROM Delta 9.0

This document tracks known issues and active bug hunting targets for **OneROM Delta 9.0** on the Samsung Galaxy S10 (`beyond1lte`). 

> [!NOTE]
> These bugs are intentionally cataloged and will be addressed together in an upcoming major version bump/fix release once community bug hunting gathers full feedback and logs.

---

## Current Known Issues

1. **Front Camera**
   - Front-facing camera fails to initialize or crashes camera apps upon switching.

2. **Fingerprint & PIN Pad Overlay**
   - The lockscreen in-display fingerprint sensor icon / prompt overlaps with the PIN entry pad and bottom indicators.

3. **Screen Recording**
   - Native screen recorder fails to capture or outputs broken video streams.

4. **Browser**
   - Using the browser causes a soft reboot.

---

## Flashing & Utilities Note

For installation and partition prep, please note:
- **Cleaner:** Uses the exact same cleaner script as **ExtremeROM Nexus**.
- **TWRP:** Uses the exact same TWRP recovery as **ExtremeROM Nexus**.
- **Repartitioning:** Uses a slightly modified repartitioner script derived from ExtremeROM (also available in the GoFile share).
